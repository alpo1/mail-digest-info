Mail Digest Bot

A personal mail monitoring tool that checks the owner's Gmail Inbox and Yahoo Inbox and Spam folders hourly and delivers new-message summaries to the owner's private Telegram chat.

The tool reads mail only. It does not send, delete, move, or relabel messages.

Privacy notice · Use

Privacy notice

The tool accesses sender names and addresses, subjects, delivery times, message identifiers and message text or snippets to create mail notifications. Gmail access uses the gmail.readonly permission.

Processing runs in a private GitHub repository using GitHub Actions. Credentials are stored in GitHub Actions Secrets. Message identifiers and checkpoints are stored privately for deduplication; message bodies are not intentionally stored in that checkpoint file. Notification content is sent to Telegram and remains subject to Telegram's storage practices and the owner's chat settings.

Google user data is used only to provide the requested personal notifications. It is not sold, used for advertising, or used to train generalized artificial intelligence models. Use of Google user data follows the Google API Services User Data Policy, including its Limited Use requirements.

The owner can stop scheduled runs, revoke Google access, remove Yahoo app credentials, and delete notifications from their Telegram chat. Revoking access prevents future collection.

Use

This application is for its owner's personal use. It is not a public sign-up service. Notifications depend on the availability of the mail providers, GitHub Actions and Telegram; scheduled runs may be delayed.
